# Provenance and redistribution boundaries

Only original project source/configuration, documentation, and the unmodified AGPL license text are intended to ship here. Calling a file a patch or marking a folder Local does not establish redistribution permission. The runtime APIs called by an original addon remain dependencies, not code relicensed by this project.
