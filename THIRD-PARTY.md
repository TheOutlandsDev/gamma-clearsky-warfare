# Component provenance and publishing decisions

Reviewed 2026-10-22 using author pages, pinned source references and local files. This records what this project can publish on the available evidence. **A reference or installation path does not grant permission to redistribute the referenced files.**

This public tree contains original project source/configuration, documentation and the unmodified AGPL license text. It contains no upstream game/mod implementation, engine executable, game asset archive or dependency installer. The [dependency and setup guide](docs/DEPENDENCIES.md) maps author sources to portable installation paths and explains the private integrations.

## Conditions for future packaging

[GitHub's content terms](https://docs.github.com/en/site-policy/github-terms/github-terms-of-service#d-user-generated-content) require the uploader to have the rights to post third-party content and comply with its license. Public hosting does not supply missing rights.

User downloads, unattended fetching, user-local repair caching, public mirroring and redistribution of modified files are separate questions. This repo has no dependency auto-downloader or hidden mirror. Respect author and hosting-service rules, including required user login or license acceptance.

Before bundling a reference-only dependency, record the exact version/hash, covered file list, license or written permission, modification terms, attribution and outside assets. Do not infer permission from silence, public source, a download button or another modpack's approval. A diff/local patcher does not bypass missing modification or distribution rights.

Requests have been drafted privately for xrRazom, REDUX, barter and WPO. **No requests have been sent and no author approvals have been received.** Drafts are not approval evidence and are not posted here.

V1 targets a free, noncommercial, clearly unofficial installer/launcher for solo and private host/join co-op. The current source companion is incomplete. Dependencies keep their own terms; their licenses are not replaced by this repository's AGPL. See [validation status](docs/STATUS.md) and [installation boundaries](docs/DEPENDENCIES.md).
